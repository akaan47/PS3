# 🤖 PS3 

Bot Discord conçu pour une interaction ergonomique avec votre **PS3 jailbreakée** afin de **recenser toutes les sources téléchargeables** disponibles (homebrews, PKG, mises à jour, etc.).

> ⚠️ **Projet obsolète et peu optimisé** : ce bot n’est plus maintenu, mais reste disponible à titre d’archive ou d’exemple.

## ⚙️ Fonctionnalités principales

- 📂 Répertoire automatisé de contenus PS3 via Discord.
- 🔍 Recherche rapide de fichiers ou homebrews par commande.

## 📚 Utilisation

Une fois le bot ajouté à votre serveur Discord, utilisez les commandes préfixées pour chercher ou afficher
